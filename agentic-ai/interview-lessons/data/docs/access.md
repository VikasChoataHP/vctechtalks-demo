# Nimbus Platform: Access Requests

## Roles
There are three namespace roles. Viewer can read logs and resources. Developer can also deploy to dev and staging. Admin can change quotas, secrets, and production settings.

## How to request access
Request a role in the Nimbus portal. Viewer and Developer are approved by the namespace owner. Admin also needs approval from your line manager.

## Access reviews
All access is reviewed every quarter. Access that has not been used for 60 days is removed automatically.
